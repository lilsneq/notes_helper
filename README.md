# 🗒️ Smart Notes Telegram Bot

Асинхронный Telegram-бот для ведения личных заметок и гибкого планирования напоминаний на базе СУБД PostgreSQL. 

Интерфейс полностью построен на динамических **Inline-клавиатурах** (event-driven), что предотвращает заспамливание истории чата новыми сообщениями и позволяет переключать экраны меню «на месте».

## 📂 Структура проекта

Соответствует текущей архитектуре каталогов приложения:

```text
PythonProject/
│
├── database/               # Модуль работы с базой данных PostgreSQL
│   ├── __init__.py
│   ├── connection.py       # Инициализация и закрытие асинхронного пула соединений
│   └── requests.py         # Все SQL-запросы к СУБД (создание, запись, чтение, слияние)
│
├── handlers/               # Модули обработки событий и команд Telegram
│   ├── __init__.py
│   ├── create_notes.py     # Логика создания и сохранения заметок через FSM
│   ├── echo.py             # Эхо-роутер для перехвата неразмеченных апдейтов
│   ├── settings_notes.py   # Обработка инлайн-кнопки «Настройки»
│   ├── show_notes.py       # Интерактивный список заметок и выбор времени таймера
│   └── start.py            # Команда /start и обработка кнопки «Назад»
│
├── services/               # Фоновые службы приложения
│   ├── __init__.py
│   └── scheduler.py        # Будильник APScheduler для ежеминутного сканирования базы
│
├── ui/                     # Визуальное оформление интерфейса
│   ├── __init__.py
│   └── menu.py             # Генераторы динамических Inline-клавиатур
│
├── .env                    # Конфигурационный файл с приватными токенами и доступами
├── .gitignore              # Исключение системных файлов и .env из Git-репозитория
├── main.py                 # Главная точка входа для запуска бота
└── requirements.txt        # Файл внешних зависимостей проекта
```

## 🗂️ Реляционная структура БД (PostgreSQL)

База данных автоматически разворачивает трехуровневую структуру связанных таблиц при первом запуске:
1. **`public.user_tg_bot`** — реестр уникальных Telegram ID пользователей.
2. **`public.notes_tg_bot`** — хранилище текстов записей. Связано связью «один ко многим» с таблицей пользователей.
3. **`public.notion_tg_bot`** — таблица таймеров планировщика. Имеет каскадную привязку `ON DELETE CASCADE` к конкретному ID заметки.

## 🚀 Инструкция по установке и запуску

### 1. Подготовка окружения
Склонируйте проект, активируйте виртуальное окружение и установите пакеты из файла зависимостей:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Конфигурация окружения
Обязательно создайте файл **`.env`** в корневом каталоге и укажите ваши валидные данные подключения:
```env
TOKENTG=ваш_актуальный_токен_от_botfather
TOKEN-BD=ваш_актуальный_токен_от_базыданных
```

### 3. Старт бота
Запуск основного процесса приложения:
```bash
python3 main.py
```

При старте в терминале последовательно отобразятся системные логи инициализации пула и успешной проверки/создания всех трех таблиц, после чего запустится фоновый цикл `polling`.
